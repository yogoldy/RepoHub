# Interaction testing and readability — superseded plan

Superseded October 20, 2026, with Leo's approval. The single current roadmap is
[the product delivery sequence](../PRODUCT_THESIS.md#next-delivery-sequence).
Its first implementation step is Dev/Testing/Stable channels; roadmap
consolidation has already been done and is not another development stage.

The former nine-stage plan is retained in Git history, not as a second active
checklist. Remaining native interaction, Show me, keyboard/reduced-motion,
permission, failure/recovery and repeatable browser checks are incorporated into
the current sequence. Existing automated and installed results retain their
original evidence limits; an unchecked historical stage does not mean all of its
underlying work is missing.

The [readability standards](READABILITY_STANDARDS.md) remain current. Broad code
cleanup and Leo's representative AI-teacher review are deferred and require
separate scope approval. No browser MCP, formatter or framework installation is
required simply because it appeared in the old plan.

The roadmap records intended work, not completed channel implementation or a
change to active release guards. Until the channels are implemented with matching
policy changes, follow [the existing delivery policy](RELEASE_DELIVERY.md) and
[agent instructions](../AGENTS.md). Application code, tests, credentials, CI,
release feeds and installed apps were not changed by this consolidation.
